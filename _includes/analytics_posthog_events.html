{% comment %} Unobtrusive custom event capture for PostHog. Uses a single delegated click listener on the document and no-ops unless window.posthog is present, so it stays inert when PostHog is disabled or skipped (blank key / localhost). Captures paper PDF clicks, CV/resume downloads, and outbound clicks to common academic profiles. All `href` properties are sanitized to strip query strings and hash fragments before they reach PostHog, so no tracking tokens, session ids, or fragment state leak into analytics; the domain is preserved for outbound attribution. {% endcomment %}
